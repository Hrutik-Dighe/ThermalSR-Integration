01 Multi-Sensor Co-Registration

Uses LoFTR (detector-free local feature matching) to extract cross-modal keypoint correspondences between optical and TIR images. RANSAC estimates a robust homography; thin-plate spline warp handles non-rigid distortion. A per-pixel alignment confidence map flags low-confidence regions (water, bare soil) for suppressed guidance.

MethodLoFTR + RANSAC homography
Warp typeHomography / thin-plate spline
OutputAligned TIR + confidence map
Accuracy target< 0.5 pixel RMSE
02 Dual-Stream Encoder

Two separate Swin Transformer backbones process optical and thermal streams independently, preserving their native representation spaces. The optical encoder extracts a 4-level FPN pyramid of edge/texture features. The thermal encoder operates in calibrated Kelvin units, not normalized pixels.

BackboneSwin Transformer-S
Feature levels4 (P2–P5)
Optical outputStructural feature maps
Thermal inputCalibrated Kelvin values
03 Cross-Modal Attention Fusion

Thermal features act as queries attending to optical keys/values. A guidance gate (scalar per spatial location) suppresses optical guidance where alignment confidence is low or where no temperature boundary should exist (glass rooftops, water bodies). Prevents optical texture bleed.

MechanismMulti-head cross-attention
Heads8
Guidance gatePer-pixel sigmoid scalar
Anti-artifactConfidence-weighted masking
04 Physics-Constrained Decoder

An auxiliary branch estimates per-pixel emissivity from land cover class (NDVI, NDWI indices from optical). The decoder applies emissivity correction before pixel-shuffle upsampling. A differentiable energy-balance loss penalizes outputs that violate surface energy balance.

UpsamplingPixel-shuffle (sub-pixel conv)
Scale factor×4 (configurable)
Emissivity srcNDVI/NDWI from optical
Physics modelSimplified SEB (simplified energy balance)
Ltotal = λ₁ · Lpixel  +  λ₂ · Lperceptual  +  λ₃ · Lphysics  +  λ₄ · Ledge
λ₁=1.0  ·  λ₂=0.1  ·  λ₃=0.05  ·  λ₄=0.2
Lpixel
Pixel / Temperature Loss
Mean absolute error in Kelvin between SR output and HR reference thermal. Directly enforces temperature fidelity — the core constraint for physical correctness.
MAE(SR, HR) = mean(|SR - HR|)
Lperceptual
Perceptual Feature Loss
VGG-16 feature-space L2 loss between SR and HR at layers conv3_3 and conv4_3. Sharpens spatial structure without hallucinating per-pixel values.
||φ(SR) - φ(HR)||² (VGG features)
Lphysics
Physics Consistency Loss
Penalizes outputs where the estimated radiative flux (from SR temperature and emissivity) violates the Stefan-Boltzmann law and energy balance. Ensures physical plausibility.
||ε·σ·T⁴_SR - L_measured||²
Ledge
Edge Alignment Loss
Chamfer distance between SR thermal edges and optically guided boundary map. Encourages sharpness at real thermal boundaries; suppresses false edges from optical leakage.
ChamferDist(edges(SR), guided_edges)

Your MATLAB script is translated step-by-step to Python (called via MATLAB Engine API for Python). This lets the FastAPI server invoke your actual MATLAB code while serving a web frontend.

MATLAB (your script) 
% Noise reduction
gray = medfilt2(gray,[5 5]);

% Contrast enhance
gray = adapthisteq(gray, ...
  'ClipLimit',0.02);

% Low-res sim
low_res = imresize(gray,0.4,'bicubic');
low_res_up = imresize(low_res,size(gray));

% Detail extraction
blur1 = imgaussfilt(low_res_up,1);
blur2 = imgaussfilt(low_res_up,2);
detail = (low_res_up - blur1) + (blur1 - blur2);

% Canny edges
edges = edge(gray,'canny');
edges = im2double(edges) * mean(gray(:)) * 1.5;

% SR fusion
SR = low_res_up + 0.6*edges + 0.4*detail;
SR = mat2gray(SR);
SR = imsharpen(SR,'Radius',2,'Amount',1.8);

% Metrics
psnr_val = psnr(SR, gray);
ssim_val = ssim(SR, gray);
